slid from rank 2213/7302 to 12029/14561 as the field grew, while the winners carried
~29 dated stories with clear hierarchy. This page carries 28 stories, each checked
against reporting dated 26 November 2026, with the three most consequential stories
large on top and the rest in a numbered grid tied to the map.

## Run it

```sh
python3 render.py        # draws entry.png (1024x1024, < 1 MiB)
python3 main.py          # copies entry.png to $MAKEFUN_OUTPUT_DIR
```

`render.py` needs only Python's standard library plus Pillow and the DejaVu
fonts; `main.py` is standard-library only. Deterministic: re-running
`render.py` produces a byte-identical PNG.
